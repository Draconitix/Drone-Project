# Drone-Project
This repository is for several mini-projects for the PySimVerse simulator, and the missions it has.

Dependencies needed are in the requirements.txt file. To run, you will need to set up a virtual environment, I used pycharm to do this on my machine automatically after opening the folder.

Video demonstrating each mission running in the PySimVerse simulator: https://youtu.be/7PUZgdgpCCg
